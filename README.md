# 🎂 致 白合 · 21 岁生日快乐

一个纯 HTML / CSS / JS 的「液态玻璃」风格生日页：星空背景、玻璃质感卡片、照片回忆墙、祝福签、许愿蛋糕。

页面骨架来自 GitHub 开源项目 [fypklanfanqie/happy-birthday-to-falt-White](https://github.com/fypklanfanqie/happy-birthday-to-falt-White)，**视觉与交互原样保留，文案与内容已全部重写为「白合 · 21 岁」版本**（原名、18 岁、高考倒计时、哈工大、B 站相识故事、JVKE 歌单等私人内容均已移除）。

## 🚀 怎么看

直接**双击 `index.html`** 即可（推荐 Chrome / Edge）。

想用本地服务器看也可以：

```bash
python -m http.server 8080
# 然后打开 http://127.0.0.1:8080
```

## 📷 照片

`assets/photos/` 里 26 张已经是**真照片**，按 2024 / 2025 / 2026 三个年份分组，桌面端排好版、手机端按 1→9 顺序单列收缩：

| 区块 | 文件名 | 张数 |
|------|--------|------|
| 2026 · 你二十一岁 | `2026-1.jpg` … `2026-9.jpg` | 9 |
| 2025 · 再往前一年 | `2025-1.jpg` … `2025-9.jpg` | 9 |
| 2024 · 更早的那一年 | `2024-1.jpg` … `2024-8.jpg` | 8 |

想换某一张？**把同名文件覆盖进去**即可，不用改任何代码。

小提示：

- 图片按 `object-fit: cover` 裁切，**横图竖图都行**，不会被拉变形。
- 每块最后的 `9`（2024 块是 `3`）是**横向大图位**，适合放横拍的照片；`2026-3`、`2025-2`、`2024-4` 是**竖长图位**，适合放竖拍的照片。
- 想换顺序？直接对调两个文件名就行。
- 照片已统一压到长边 1600px、JPEG 质量 86（26 张共约 7 MB），清晰度和体积比较平衡。

## ✏️ 想改文字

`index.html` 里所有中文都是明文，直接搜关键词改：

- 名字：搜 `白合`（标题、导航、Hero、结尾、页脚共 5 处左右）
- 年龄：搜 `二十一岁` / `21`
- 生日日期：搜 `11 月 22 日`（首屏那句）和 `2026.11.22`（页脚）
- 祝福签的 6 句话：搜 `data-wish`
- 写给你的信：搜 `写给你的话`

改动后保存、刷新浏览器即可生效，不需要重新构建。

### 🎂 生日倒计时怎么改

首屏的「距离你的生日还有 X 天」和「二十一」那节的徽标都是**按日期自动算的**，不用手动改数字。日期写在 `index.html` 最末尾的脚本里：

```js
const BIRTH_YEAR=2026, BIRTH_MONTH=10, BIRTH_DAY=22;  /* 10 = 十一月 */
```

注意月份是从 **0** 开始的（`10` = 11 月）。改完刷新即可：生日前显示「还有 N 天」，生日当天自动变成「今天就是你的生日 🎂」，过了生日显示「二十一岁，生日快乐」。
